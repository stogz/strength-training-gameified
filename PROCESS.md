# Development Process

I am using Scrum for the gamified strength training system. I selected Scrum because the project combines stable workout-tracking requirements with gamification requirements that may need refinement after implementation and user testing.

Sprint length: 2 weeks
Sprint 1 goal: Create a functional core that supports workout recording, basic XP, and visible progression.
